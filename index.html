Tooth Fairy Run — Privacy Policy

Effective date: October 6, 2026

Tooth Fairy Run ("the game") is a running game for phones and tablets published by Qira Studio. The game does not collect, store, or share any personal data. It has no accounts, no ads, no analytics, no in-app purchases, and no third-party SDKs that collect data.

Data collection

Tooth Fairy Run does not collect any data. There is no sign-up or login, and the game does not use the internet, so nothing ever leaves your device. Your game progress (completed levels, stars, golden hearts, stardust, upgrades and settings) is saved only locally on your device and is never transmitted anywhere. Uninstalling the game removes this saved progress.

Ads, analytics and purchases

The game shows no advertising, contains no analytics or tracking tools, and offers no in-app purchases. No information is shared with or sold to any third party, because no information is collected.

Permissions

On Android the game requests only the vibration permission, used for haptic feedback during play. It does not request internet access, location, camera, microphone, contacts, or any other sensitive permission.

Children

Tooth Fairy Run is suitable for children. It does not knowingly collect any information from anyone, including children, because it collects no information at all. The game contains no ads, no purchases, no chat, and no links to social networks.

Changes to this policy

If any of the above ever changes — for example, if a future version adds ads, purchases, or any kind of data collection — this policy will be updated before that version is released, and the updated version will be published at this same address.
